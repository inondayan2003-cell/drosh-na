# דרוש-נא

דרשה מוכנה לשבת, לחג או לאירוע, באורך שאתה בוחר, תוך פחות מדקה.

שני מימושים באותו ריפו:
- **אתר** (הקבצים בתיקייה הזו) — HTML/CSS/JS רגילים, בלי שרת, בלי שלב build. עובד גם בפתיחה מקומית וגם ב-GitHub Pages.
- **אפליקציה נטיבית** ([mobile/](mobile/)) — iOS ו-Android, Expo + Expo Router. ראה [mobile/README.md](mobile/README.md) להרצה.

## מבנה הריפו

```
drosh-na/
  index.html   האפליקציה (מסכים, ניווט, עיצוב, זיהוי פרשה)
  data.js      המאגר — window.DROSH_DATA
  README.md
```

## הרצה מקומית

פתיחה ישירה של `index.html` בדפדפן עובדת. לחלופין:

```bash
python3 -m http.server 8000
```

ואז גלישה אל `http://localhost:8000`.

## עדכון המאגר

`data.js` הוא הממשק היחיד בין התוכן לאפליקציה. המבנה המלא מתועד בראש הקובץ ובאפיון המוצר. **הנתונים שבקובץ כרגע הם דוגמה בלבד** (כמה פרשות ונושאים, חלקם עם דרשה מלאה וחלקם `null` כדי להדגים את מצב "בקרוב") — כתיבת תוכן הדרשות האמיתי היא מחוץ להיקף הקוד ותתבצע בנפרד.

כל עוד מבנה ה-JS נשמר:

```js
window.DROSH_DATA = {
  parashot: {
    "בראשית": { short: DRASHA, long: DRASHA }
  },
  topics: [
    { name: "שמחה", tags: ["סוכות", "חג"], short: DRASHA, long: DRASHA }
  ]
};
// DRASHA = { title: "כותרת", text: ["פסקה 1", "פסקה 2"] }  או null
```

שמות הפרשות ב-`parashot` חייבים להיות בדיוק כמו ב-54 השמות שבקוד (`PARASHA_ORDER` בתוך `index.html`), בלי המילה "פרשת".

## פריסה ל-GitHub Pages

1. Push לענף הראשי.
2. Settings → Pages → Source: Deploy from a branch → `main` / `root`.
3. האתר יעלה בכתובת `https://<user>.github.io/drosh-na/`.

## מה ה-MVP כולל

- שני מסלולים: פרשת שבוע (זיהוי אוטומטי דרך Hebcal API, כולל טיפול בפרשיות מחוברות ובשבתות שחלות בחג) ודרשה כללית (חיפוש נושאים לפי שם ותגיות).
- בחירת אורך (קצרה/ארוכה) עם זמן דיבור מחושב מהטקסט (מילים ÷ 120).
- מסך קריאה: הגדלת/הקטנת טקסט (80%–180%), העתקה ללוח, שיתוף (Web Share API כשנתמך).
- עיצוב RTL מלא, מצב כהה אוטומטי, `prefers-reduced-motion`, מובייל תחילה.

## מה עוד לא נכלל (v2 והלאה, לפי האפיון)

- PWA (manifest + service worker) להתקנה ועבודה אופליין.
- מועדפים, "מצב דרשן" (מסך שלא נכבה).
- דומיין, תקנון, מדיניות פרטיות, הצהרת נגישות רשמית, אנליטיקה.
- הרחבת AI בתשלום.
